## Checked and fine

- **Tenancy:** only the three documented `workspaces` repository exceptions exist; every repository has a cross-workspace isolation test; no module queries another's tables.
- **Conventions and migrations:** `newId()` everywhere; config only in `config.ts`, and `.env.example` matches; migrations are reversible, with no triggers and no DB defaults.
- **Sessions, tokens and passwords:**
  - cookie flags match ADR-0002;
  - tokens are 32 bytes, stored as SHA-256 hashes only, and consumed by a conditional update;
  - argon2id (19 MiB, t=2, p=1) with a timing-safe compare and a dummy verification for unknown emails.
- **Guard:** a never-member gets 404 and a deactivated member gets `ACCESS_REMOVED`, read on every request without a cache.
- **Admin CLI:** calls `deps.destroy()` on every path; audit lines carry ids only.
- **Web:** shadcn primitives with `cn` from `@/shared/lib/utils`, Tailwind only, every response parsed with the shared zod schemas, same-origin `/api`, no `dangerouslySetInnerHTML`, and the invitation link lives only in local state.
