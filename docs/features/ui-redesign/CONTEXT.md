# Domain Context — ui-redesign

> Feature-scoped terms. Read together with the repo-root [CONTEXT](../../../CONTEXT.md); an entry here wins on conflict.

## Glossary

- Preview screen — a web-panel screen for a capability that is not built yet (the shared inbox, the contact list, a contact's profile), filled with built-in sample data that is visibly labelled as sample data, the same for every workspace, and never saved. NOT a workspace's real conversations or contacts (those arrive with roadmap steps 4 and 7 and replace the sample data).
- Sample data — invented conversations, messages and contacts shipped inside the web panel so a preview screen looks populated; it names no real person and belongs to no workspace. NOT a Contact or a Conversation (it is never captured from a business bot).
